  RAPPROCHEMENT ASSURANCES PRO - DEMARRAGE RAPIDE (5 MINUTES)

🎯 OBJECTIF: Avoir l'application complète en fonctionnement

================================================================================
ETAPE 1 - INSTALLER PYTHON & GIT (5 minutes)
================================================================================

Windows:
  1. Télécharger Python 3.9+ : https://www.python.org/downloads/
  2. Cocher "Add Python to PATH" pendant l'installation
  3. Télécharger Git : https://git-scm.com/download/win

Mac:
  1. Installer Homebrew: /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  2. Terminal: brew install python3 git

Linux (Ubuntu/Debian):
  Terminal: sudo apt install python3 python3-venv git

================================================================================
ETAPE 2 - CLONER ET CONFIGURER (2 minutes)
================================================================================

Terminal/CMD:
  1. cd /chemin/vers/votre/dossier
  2. git clone <url_du_repo>
  3. cd claudeapps
  4. python -m venv venv
  5. # Windows: venv\Scripts\activate | Mac/Linux: source venv/bin/activate
  6. pip install -r requirements.txt

================================================================================
ETAPE 3 - DEMARRER LE SERVEUR (1 minute)
================================================================================

OPTION A - Automatique (Windows):
  Double-cliquez sur: START.bat

OPTION B - Automatique (Mac/Linux):
  Terminal: chmod +x START.sh && ./START.sh

OPTION C - Manuel:
  Terminal: python backend_api.py

Résultat attendu:
  INFO:     Uvicorn running on http://0.0.0.0:8000
  INFO:     Application startup complete

✅ Vérifier: http://localhost:8000/docs

================================================================================
ETAPE 4 - LANCER L'APPLICATION DESKTOP (< 1 minute)
================================================================================

NOUVELLE FENETRE de Terminal/CMD (garder l'autre ouverte):
  Windows: venv\Scripts\activate && python app_desktop.py
  Mac/Linux: source venv/bin/activate && python app_desktop.py

FENETRE PRINCIPALE APPARAÎT:
  ✅ Dashboard avec statistiques temps réel
  ✅ Onglet "Alertes" vide (aucune alerte pour le moment)
  ✅ Onglet "Rapports" vide (aucun rapport généré)
  ✅ Onglet "Configuration" pour les paramètres

================================================================================
ETAPE 5 - LANCER L'APPLICATION MOBILE (optionnel - 5 minutes)
================================================================================

Pré-requis: Node.js 14+ installé (https://nodejs.org/)

NOUVELLE FENETRE de Terminal:
  1. cd claudeapps
  2. npm install -g eas-cli expo-cli
  3. npx create-expo-app RapprochementMobile
  4. cd RapprochementMobile
  5. npm install @react-navigation/native @react-navigation/bottom-tabs react-native-screens react-native-safe-area-context react-native-gesture-handler react-native-reanimated @react-native-async-storage/async-storage expo-notifications react-native-chart-kit
  6. cp ../app_mobile.js ./App.js
  7. expo start
  8. Taper 'a' pour Android ou scanner QR code avec l'app Expo Go

================================================================================
TESTER RAPIDEMENT

Depuis l'app Desktop:
  1. Cliquer sur "🚀 Générer Rapport"

================================================================================
PROBLEMES COURANTS
================================================================================

"ModuleNotFoundError: No module named..."
→ Solution: pip install -r requirements.txt

"Address already in use" (port 8000)
→ Solution: Fermer l'autre instance ou utiliser un autre port:
  python backend_api.py --port 8001

"Connection refused" depuis mobile
→ Solution: Utiliser l'adresse IP locale au lieu de localhost
  Dans app_mobile.js, ligne 15: const API_URL = 'http://192.168.x.x:8000';

"PDF non reconnu"
→ Solution: Vérifier que le fichier PDF suit le bon format
  Consulter journal_diagnostic.txt généré après chaque rapport
